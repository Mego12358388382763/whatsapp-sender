# ريلز «رحلة التعافي الذاتي»: موشن جرافيكس بـ Remotion

الريل 1080×1920. فيديوك بيبقى في **النص اللي فوق**، والموشن جرافيكس في **النص اللي تحت**: أرقام بتعدّ، وجمل بتظهر كلمة كلمة، وأعمدة مقارنة، وقوايم، وكروت تحذير، ومصدر كل معلومة.

## الملفات

| الملف | فيه إيه |
|---|---|
| `SCRIPTS.md` | سكريبت كل ريل: الكلام اللي هتقوله، وتوقيته، واللي هيظهر على الشاشة، ومصدره |
| `src/data/reels.ts` | **المكان الوحيد اللي بتعدّل فيه**: الكلام والأرقام والتوقيتات والمصادر |
| `src/components/Scenes.tsx` | أشكال المشاهد (رقم، مقارنة، قائمة، جملة، تحذير، معادلة، تابعني) |
| `src/Reel.tsx` | تقسيم الشاشة (الفيديو فوق والجرافيكس تحت) |
| `public/videos/` | هنا تحط فيديوهاتك: `reel-01.mp4` و `reel-02.mp4` … |

## خطوات الشغل

1. اقرا `SCRIPTS.md` وصوّر كل ريل **رأسي**، ووشك في النص اللي فوق من الكادر.
2. سمّي الفيديو باسم الحلقة وحطه في `public/videos/`، مثلًا `public/videos/reel-01.mp4`. الصوت بيتاخد من الفيديو نفسه.
3. التشغيل:
   ```bash
   npm install
   npm run studio                # معاينة وتعديل في المتصفح
   npm run render -- reel-01     # إخراج ريل واحد إلى out/reel-01.mp4
   npm run render                # إخراج كل الريلز
   npm run scripts               # تحديث SCRIPTS.md بعد أي تعديل
   ```
4. **ظبط التوقيت:** كل مشهد ليه `at` (بيبدأ امتى بالثواني) و `dur` (مدته). لو كلامك في الفيديو طلع أبطأ أو أسرع، عدّل الأرقام دي في `src/data/reels.ts`. أو قول لـ Claude Code مثلًا: «في reel-01 الرقم 10 سنين لازم يظهر عند الثانية 24»، وهو يظبطها.

> مدة الريل بتتحسب من آخر مشهد. لو فيديوك أطول منها، زوّد `dur` بتاع آخر مشهد.

> لما يكون ملف الفيديو مش موجود، بيظهر مكانه شكل مؤقت مكتوب عليه «مكان الفيديو بتاعك».

## في جلسة Claude Code على الويب

متصفح Chromium متسطب جاهز. لو Remotion ما لقاش متصفح، شغّل الأمر كده:
```bash
REMOTION_CHROME=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell npm run render -- reel-01
```
